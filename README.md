# Vespa Grand Opening 2026 · เวสป้าเชียงราย นิยมพานิช สาขาประตูสลี

เว็บไซต์เชิญร่วมงาน Grand Opening (หน้าเดียว) — **A New Chapter. A New Ride.**
เป็นไฟล์ HTML ล้วน ไม่ต้องติดตั้งอะไร ใช้กับ GitHub Pages ได้ทันที

## ไฟล์ในชุดนี้

| ไฟล์ | ใช้ทำอะไร |
|---|---|
| `index.html` | หน้าเว็บ (ไม่ต้องแก้) |
| `config.js` | **ไฟล์ที่ใช้แก้ทุกอย่าง** — ข้อความ วันเวลา กำหนดการ ลิงก์ Google Form รูปภาพ |
| `images/` | โฟลเดอร์ใส่รูปจริง (รถ โชว์รูม) |

## 1. ขึ้นเว็บด้วย GitHub Pages

1. เข้า GitHub > **New repository** ตั้งชื่อ เช่น `vespa-grand-opening` เลือก **Public** > Create
2. กด **Add file > Upload files** ลากไฟล์ `index.html`, `config.js`, `README.md` และโฟลเดอร์ `images` ขึ้นไป > **Commit changes**
3. ไปที่ **Settings > Pages**
   - Source: **Deploy from a branch**
   - Branch: **main** / โฟลเดอร์ **/(root)** > Save
4. รอ 1–2 นาที เว็บจะอยู่ที่ `https://<ชื่อบัญชี>.github.io/vespa-grand-opening/`

## 2. ใส่ลิงก์ Google Form

1. เปิด Google Form > ปุ่ม **ส่ง** > แท็บ **ไอคอนลิงก์** > คัดลอกลิงก์ (ไม่ต้องติ๊ก "ย่อ URL")
2. เปิด `config.js` บน GitHub > ไอคอนดินสอ ✏️ > วางลิงก์ใน

```js
forms: {
  rsvp: "https://docs.google.com/forms/d/e/XXXX/viewform",      // ยืนยันเข้าร่วมงาน
  referral: "https://docs.google.com/forms/d/e/YYYY/viewform",  // เพื่อนแนะนำเพื่อน
  rsvpHeight: 1200,      // ถ้าฟอร์มถูกตัด/มีที่ว่างเยอะ ปรับตัวเลขนี้
  referralHeight: 1400,
},
```

3. กด **Commit changes** รอสักครู่แล้วรีเฟรชเว็บ

ฟอร์มจะถูกฝังในหน้าเว็บ (section RSVP และหน้าลงทะเบียนแยก) ถ้าใช้ลิงก์สั้น `forms.gle` จะแสดงเป็นปุ่มเปิดฟอร์มแทน

**ตั้งค่า Google Form ที่ควรเช็ก** (ไม่งั้นลูกค้าจะต้องล็อกอิน Google ก่อนกรอก)
- การตั้งค่า > คำตอบ > **ปิด** "จำกัดให้ตอบได้ 1 ครั้ง"
- ถ้าใช้ Google Workspace ของบริษัท: **ปิด** "จำกัดเฉพาะผู้ใช้ในองค์กร"

**ดูข้อมูลผู้ลงทะเบียน:** Google Form > แท็บ **คำตอบ** > **ลิงก์กับชีต** (Google Sheets) หรือดาวน์โหลด CSV เปิดใน Excel

## 3. ลิงก์สำหรับส่งให้ลูกค้า

| หน้า | ลิงก์ |
|---|---|
| หน้าเว็บหลัก (มี Glitter ตอนเปิด) | `https://<ชื่อบัญชี>.github.io/vespa-grand-opening/` |
| หน้ายืนยันเข้าร่วมงาน | ต่อท้ายด้วย `#rsvp` |
| หน้าเพื่อนแนะนำเพื่อน | ต่อท้ายด้วย `#referral` |

## 4. ใส่รูปจริง

1. อัปโหลดรูปเข้าโฟลเดอร์ `images/` (แนะนำ .jpg ไม่เกิน ~500 KB ต่อรูป)
2. แก้ใน `config.js`

```js
images: {
  hero: "images/hero.jpg",        // ภาพหลักหน้าแรก (แนวตั้ง 4:5)
  model: "images/ivory.jpg",      // รถรุ่นใหม่ สี Ivory
  gallery1: "images/grigio.jpg",  // สี Grigio
  gallery2: "images/oro.jpg",     // สี Oro
  gallery3: "images/rosso.jpg",   // สี Rosso
  map: "",                        // ภาพแผนที่/โชว์รูม
},
```
เว้นว่าง `""` = ใช้ภาพวาดประกอบเดิม

## 5. แก้ข้อความอื่น ๆ

ทุกอย่างอยู่ใน `config.js` — ชื่องาน วันที่ (`dateISO` รูปแบบ ปี-เดือน-วัน ค.ศ.) เวลา ข้อความเชิญ (ใช้ `\n` เพื่อขึ้นบรรทัดใหม่) ข้อมูลรถ กำหนดการ Friend Get Friend ที่อยู่ เบอร์โทร LINE ลำดับ section และสีธีม
ปิดเว็บชั่วคราว: ตั้ง `published: false` จะแสดงหน้า Coming soon

> ⚠️ ข้อความต้องอยู่ในเครื่องหมาย `"..."` และคั่นแต่ละรายการด้วย `,` ถ้าแก้แล้วหน้าเว็บว่าง ให้ตรวจเครื่องหมายเหล่านี้

## หมายเหตุ

- เวอร์ชันนี้ไม่มีระบบหลังบ้าน/รหัสผ่าน เพราะ GitHub Pages เป็นเว็บแบบไฟล์อย่างเดียว การแก้เนื้อหาทำผ่าน `config.js` และข้อมูลผู้ลงทะเบียนอยู่ใน Google Form
- Glitter แสดงครั้งเดียวตอนเปิดหน้าเว็บหลัก (~5 วินาที) และจะไม่แสดงสำหรับผู้ที่ตั้งค่า "ลดการเคลื่อนไหว" ในเครื่อง
